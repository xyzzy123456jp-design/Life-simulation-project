# LifeSimulation 開発進捗

更新日: 2026年8月17日

## 1. 会話シーン設定の外部化

- 会話地点の設定を `Config/ConversationScenes.ini` へ移行した。
- 教室、映画館、彼女の部屋、散歩、レストランなどの位置と背景オフセットを外部設定から読み込む構成にした。
- 各地点への移動、Jenniferの配置、背景配置を確認した。
- 音声関連の設定とは分離して管理している。

## 2. 音声会話

- 起動時にRealtime APIへ自動接続しない構成へ変更した。
- 通常は従来方式（Whisper／Chat／TTS）で会話する。
- `F9`キーでRealtime APIの接続・切断を切り替える設計にした。
- マイク入力、APIクレジット不足、途中で応答しなくなる問題を調査した。
- 直近の確認では、ユーザー発話とAI応答がログへ記録されている。

確認例:

```text
You: Hello.
AI: Hey there! How's it going?
```

## 3. Jenniferの顔変更

- Meshy製「Crimson Gaze」の顔をJenniferへ導入した。
- 顔のサイズと位置を既存キャラクターへ自動整列する処理を追加した。
- Crimson Gazeをデフォルト表示とし、古い顔は通常表示しない構成にした。

### MetaHuman化の試行

- 顔形状の適合を実施した。
- 顔リグとブレンドシェイプを生成した。
- テクスチャソースを取得した。
- UE 5.8のFinal Assemblyで `TextureGraph.dll` がクラッシュするため、完成版MetaHumanへの切り替えは保留している。

## 4. 口パクと歯の問題

以下の方式を検証した。

- Crimson Gazeへ `jawOpen` モーフを追加。
- 独立した歯メッシュを追加し、口の開閉へ追従させる方式を検証。
- 閉口時にも歯が見える問題を調査。
- ログから、実際の歯セクションは非表示になっていることを確認。
- 水色の線は歯ではなく、加工時に作った口の切れ目または口腔部分が見えていたことを特定。
- 口腔の透明化も試したが、見た目は改善しなかった。
- 最終的に加工済みの穴、歯、口腔を撤去し、未加工のCrimson Gaze顔へ戻した。
- この変更により、閉口時の水色の線は解消した。

### 現在の口パク方式

- 元の自然な閉口形状をそのままBasisとして使用する。
- 顔のポリゴンを切り抜かない。
- 歯と口腔は追加しない。
- 発話時だけ下唇を小さく下げる `jawOpen` モーフを使用する。
- 現状は実用上許容できる見た目まで改善している。

## 6. プレイ開始時のフリーズ

プレイボタンを押してからJenniferが表示されるまで長時間停止する問題を調査した。

ログで確認した変更前の状態:

- Crimson Gaze顔: 約156万頂点
- アセット容量: 約422MB
- Skeletal Mesh構築時間: 60.07秒
- PIE全体の開始時間: 62.56秒

実施した対策:

- 顔メッシュを約25%まで軽量化した。
- 頂点数を約156万から約39万へ削減した。
- アセット容量を約422MBから107.7MBへ削減した。
- 自然な閉口形状と簡易口パクモーフを維持した。
- 軽量版をUEへ再インポートした。
- 軽量版のインポート時メッシュ処理は約25秒まで短縮した。

軽量化後の実際のPIE開始時間は、改めて計測する必要がある。

## 7. Unreal／Codex実行環境の問題

- `dotnet.exe` が例外 `0xe0434352` で終了する問題が複数回発生した。
- UEコマンドレット実行時にDerived Data Cacheへ書き込めず、クラッシュする問題を確認した。
- 欠落していた以下のフォルダを作成した。

```text
C:\Users\hueda\AppData\Local\UnrealEngine\Common\DerivedDataCache
C:\Users\hueda\AppData\Local\UnrealEngine\Common\Zen\Data
```

- `-DDC-ForceMemoryCache` を使うことで、顔アセットのインポートは完了した。
- Zen Serverは保存先を正しく認識できておらず、警告が残っている。
- キャッシュ問題の恒久修正は未完了。
